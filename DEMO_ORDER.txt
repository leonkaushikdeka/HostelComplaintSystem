HOSTEL COMPLAINT MANAGEMENT SYSTEM
5 MINUTE DEMO ORDER

BEFORE THE VIVA
    1. Run compile.bat once. It should say "Compilation successful."
    2. Delete data\complaints.txt so the 10 sample complaints load fresh with dates
       counted back from today. (If the file is missing the program creates it.)
    3. Keep the Command Prompt window visible next to the program. The console
       output is part of the demo.
    4. The escalation check runs 15 seconds after start. Log in as the Warden quickly
       (step 0:10) to watch it change the table live.
